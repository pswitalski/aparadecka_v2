# web — Astro site

Astro site for the artist portfolio. Renders content from Sanity CMS and deploys to
Cloudflare Pages. See the root `README.md` for deployment, env vars, and CI.

## Commands

- `npm run dev` — dev server
- `npm run build` — static build
- `npm run check` — `astro check` plus `tsc --noEmit -p functions` (typechecks the Pages Function too)
- `npm run preview` — preview the built site
- `npm run lint` — ESLint

## Routes

- `/` — `src/pages/index.astro`, home page (featured paintings)
- `/o-mnie` — `o-mnie.astro`, About page
- `/portfolio` — `portfolio/index.astro`, year collections
- `/portfolio/[year]` — `portfolio/[year].astro`, paintings within a year
- `/kontakt` — `kontakt.astro`, contact page + form
- `/robots.txt` — `src/pages/robots.txt.ts`, generated at build time (see root README)
- `/sitemap-index.xml` — generated by `@astrojs/sitemap`

## Features

- **Home page** — shows the featured paintings using `src/components/home-gallery/`: desktop
  (`DesktopGallery`, a custom slot layout in `geometry.ts` animated with `motion`) and mobile
  (`MobileGallery`, an `embla-carousel` with autoplay) variants behind a shared `adapter.ts`.
- **Portfolio** — `/portfolio` is a grid of year cards; `/portfolio/[year]` lists that year's
  paintings as `PaintingCard.astro`, each opening full-screen in `PaintingLightbox.astro`.
- **About page** — `AboutSections.astro` renders the CMS `about.sections` blocks responsively:
  - Desktop — image beside the text (left/right per block, image column ~30% of the content width)
  - Mobile — image stacked above or under the text
  - Highlighted blocks get a full-bleed white band that hugs the text
  - Captions reveal on hover/focus on desktop, and are always visible on mobile
  - Text-only blocks span the full content width with the chosen alignment
- **Contact form** — `components/contact/ContactForm.astro` posts JSON to `/api/contact`; the
  `functions/api/contact.ts` Pages Function validates it and emails the owner (see root README for
  the required env vars). Includes a honeypot field and a visible Cloudflare Turnstile widget
  (`Turnstile.astro`); the endpoint also enforces a same-origin check and a per-IP rate limit.
  Messages are not stored.
- **Rich text** — `PortableText.astro`, `PortableTextImage.astro`, `BigSmallBlock.tsx`, and the
  navigation components under `components/navigation/` (including `MobileMenu`).

## Styling & data

- Styles are `vanilla-extract` (`*.css.ts`) plus SCSS (`src/styles/globals.scss`) and shared
  tokens from `../shared/` (`tokens.css`, `rich-text.css`).
- `src/lib/` holds the Sanity client (`sanity.ts`), GROQ queries (`queries.ts`), and types
  (`types.ts`); `sanity.types.ts` is generated from the Studio schema (`npm run types` in `studio/`).
- `integrations/preload-islands.mjs` is a custom Astro integration that injects
  `<link rel="modulepreload">` tags for island chunks, so their imports load in parallel instead of serially.

## Environment

- `.env.example` — `PUBLIC_SANITY_PROJECT_ID`, `PUBLIC_SANITY_DATASET`, `PUBLIC_SITE_ENV`
  (`production` makes `/robots.txt` indexable; anything else keeps previews out of search), and
  `PUBLIC_TURNSTILE_SITE_KEY`.
- `.dev.vars.example` — env for the Pages Function (`CLOUDFLARE_*`,
  `CONTACT_NOTIFICATION_EMAIL`, `CONTACT_FROM_EMAIL`, `TURNSTILE_SECRET_KEY`).
